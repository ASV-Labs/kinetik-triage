# Alpha feedback

Use the issue templates for a reproducible bug or a focused improvement request. Start with the version/build and macOS version, then explain what you tried, what you expected, and what happened.

The current pilot uses P0GL0L public activity. Account selection, private repositories, team synchronization, and deployment actions are outside its present scope. Requests in those areas are welcome as feedback, not promises of a delivery date.

Review attachments before posting: all issues in this repository are public. Never include secrets, private repository contents, or unrelated personal details. No service-level response time is promised for this early alpha.

The application source is maintained separately. Website or documentation suggestions can be discussed in an issue; do not assume that this repository grants an open-source license.
