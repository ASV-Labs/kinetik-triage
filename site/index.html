01 READ THE CHANGE

Start with what
actually changed.

A pull request is a proposed software change. An issue is a task, bug report, or discussion. Kinetik brings these together with project activity so you can decide where to look first.

Each case shows its source, current state, risk band, and evidence coverage. Open the source on GitHub to read the original work.

Before you try it.

How does invitation-only access work?

Apply by email, then wait for a personal reply. We share installation instructions with approved testers after the package passes its release checks. The desktop pilot has no account login or license enforcement, so please do not redistribute an invited build.

How do I get updates?

Approved testers receive new verified builds and release notes through the private invitation channel. Quit Kinetik before replacing the app. Your review files stay on your Mac; back them up before testing a new alpha. There is no automatic updater in this version.

Do I need to be a developer?

You can follow the guide without writing code. Familiarity with the project helps you judge a change. Kinetik organizes evidence; it does not replace the people who understand that software.

Can I connect my own projects?

Not in this alpha. The current pilot uses public P0GL0L activity, which can include contributions to other repositories. There is no profile picker, private repository access, or GitHub sign-in.

Does “Approve locally” change GitHub?

No. All decisions stay on this Mac. Nothing is merged, deployed, or published. Defer records a decision but does not schedule a reminder.

What happens without an internet connection?

The app can show its last saved public queue when available. It labels cached or failed loads so you know the data may be old. A first launch without data can show an empty queue and an error.

Where does my information go?

The desktop app requests public GitHub data; GitHub sees ordinary network metadata. Your rationale and local decisions are not sent to GitHub. This landing page has no analytics or form submission service. Applying opens your email app; you choose whether to send your application to ASV Labs. Your email provider processes that message.
