# Privacy notice

Last updated: 21 September 2026. Applies to Kinetik Triage 0.9.5/build 4 and this alpha website.

## Desktop app

Kinetik requests public GitHub activity for P0GL0L directly from GitHub's API. Requests include ordinary HTTP headers and identify the requested public endpoint. GitHub receives network information such as your public IP address. GitHub's own privacy practices apply to its service.

Kinetik stores your decisions, rationale, selected case, cached public data, and exports in `~/Library/Application Support/Kinetik Triage/`. The app does not upload your local rationale or decisions, request a GitHub access token, or include a Kinetik analytics/crash reporting service in this alpha. Following a source or help link opens your browser and visits that destination.

These are ordinary local files, not an encrypted vault. Other users/processes with access to your macOS account, your backup system, or synchronization tools may access or copy them. Protect the account and review your backup settings. Quit the app before backing up or removing the folder; removing it clears local review state and cached data.

## Exports and support

Exporting writes files locally. If you choose to attach a report or screenshot to a public GitHub issue, it becomes publicly visible. Review it first for personal information, local paths, review activity, repository names, and error details. Never post credentials or private source code.

## Website

The landing page has no analytics script, advertising pixels, cookies, account system, or form-submission backend. Its interactive example stays in the page's memory and is cleared by reset or navigation. GitHub Pages serves the site and may process connection information according to GitHub's policies. External links take you to their respective services.

## Questions

Use the repository's public issue tracker for general privacy questions, without including sensitive information. This notice describes the current alpha; future account, synchronization, or telemetry features require an updated notice.
